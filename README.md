# 🪪 CardLink - 스마트 디지털 명함 & 근거리 공유 시스템

QR 코드 스캔 및 근거리 공유(Quick Share / AirDrop / NFC)를 통해 별도의 앱 설치 없이 스마트폰으로 나의 명함을 바로 전달하고 주소록에 등록할 수 있는 **서버리스 클라이언트 웹 애플리케이션**입니다.

---

## 🌟 핵심 기능

0. **📷 실물 종이 명함 사진 AI 스캐너 & QR 코드 자동 생성 (신규)**:
   - 스마트폰으로 기존 종이 명함을 찍거나 사진을 올리면 텍스트를 자동 인식(OCR)합니다.
   - 성명, 영문 이름, 회사명, 직책/직함, 부서, 휴대전화, 유선전화, 이메일, 웹사이트, 주소, 슬로건을 지능형 알고리즘으로 자동 분류/추출합니다.
   - **스마트 명함에 즉시 반영됨과 동시에 스마트폰 스캔용 고화질 QR 코드가 즉각 자동 생성**됩니다.
   - 모바일 카메라 즉시 촬영, 웹캠 뷰파인더 촬영, 사진 파일 드래그 앤 드롭, 회전/대비 보정 툴, 샘플 명함 1초 테스트 기능 제공.
   - 브라우저 내장 스마트 OCR(100% 무료/무제한) 및 Google Gemini Vision AI 모드(옵션) 지원.

1. **인터랙티브 스마트 명함 제작 스튜디오**:
   - 성명, 직책, 회사, 전화번호, 이메일, 웹사이트, 주소, 자기소개 및 프로필 사진 업로드 (자동 경량화)
   - SNS & 채널 링크 동적 추가 (LinkedIn, GitHub, Instagram, 카카오톡 오픈채팅, YouTube 등)
   - 6가지 프리미엄 디자인 테마 (Midnight, Cyber Blue, Emerald, Sunset Coral, Royal Gold, Minimalist)
   - 모바일 & 데스크톱 실시간 반응형 미리보기 및 3D 카드 틸트 / 플립 효과

2. **2가지 모드의 고화질 QR 코드 생성**:
   - **웹 디지털 명함 QR (권장)**: 카메라로 스캔 시 감각적인 풀스크린 웹 명함이 열리며, 원클릭으로 주소록 저장이 가능합니다.
   - **오프라인 연락처 직통 QR (MECARD)**: 비행기 안이나 지하실 등 인터넷이 안 터지는 환경에서도 스마트폰 카메라로 비추면 즉시 전화번호부에 저장됩니다.
   - QR 코드 이미지(PNG) 고화질 다운로드 지원 (인쇄물, 발표 슬라이드, 프로필에 사용).

3. **근거리 공유 (Proximity Sharing)**:
   - **Web Share API**: 모바일 네이티브 공유 시트를 열어 **Quick Share(갤럭시/안드로이드)** 및 **AirDrop(아이폰/Mac)**으로 명함을 즉각 전송합니다.
   - **Web NFC (NDEFReader)**: 안드로이드 크롬 등 지원 환경에서 실물 NFC 카드나 태그에 내 명함 URL을 직접 기록할 수 있습니다.
   - **원클릭 명함 링크 복사**: 카카오톡이나 메시지 채팅방에 바로 전달 가능.

4. **vCard (.vcf) 표준 주소록 원클릭 저장**:
   - RFC 2426 표준 규격으로 한글 및 특수문자가 깨지지 않는 vCard 3.0 파일 생성.
   - 상대방이 **[연락처에 저장하기 (vCard)]**를 누르면 스마트폰 주소록에 사진, 이름, 소속, 직함, 연락처, 주소가 자동 입력됩니다.

5. **완전 무료 & 제로 백엔드 (Zero-Backend)**:
   - 모든 명함 정보가 URL 해시(`index.html#card=...`)에 안전하게 인코딩되어 전달되므로, 유료 서버나 데이터베이스 비용이 전혀 들지 않습니다.
   - 내 브라우저 로컬 저장소(`localStorage`)에 자동 저장되어 언제든 다시 접속해 수정할 수 있습니다.

## 🚀 빠른 실행 방법

### 방법 1. 더블 클릭으로 바로 열기 (초간단)
* 폴더 안의 `index.html` 파일을 더블 클릭하여 크롬, 사파리, 엣지 등 아무 브라우저에서 바로 열 수 있습니다.

### 방법 2. 로컬 웹 서버로 열기 (권장)
스마트폰과 같은 Wi-Fi에 연결하여 테스트하려면 로컬 개발 서버를 띄우면 편리합니다:
```bash
# Node.js가 설치되어 있는 경우 (현재 폴더에서 실행)
npx serve .
# 또는
npx vite
```

## 🌐 무료 웹 배포 방법 (내 도메인/인터넷 주소 만들기)

이 프로젝트는 순수 HTML, CSS, JavaScript로 구성되어 있어 어디서든 무료로 1분 만에 배포할 수 있습니다:

### 옵션 A: GitHub Pages (완전 무료)
1. GitHub에 새 저장소(Repository)를 만듭니다 (예: `my-card`).
2. 이 폴더의 파일들을 업로드하고 커밋/푸시합니다.
3. 저장소의 `Settings` -> `Pages`에서 Branch를 `main`으로 설정하고 저장합니다.
4. `https://<내아이디>.github.io/my-card/` 주소로 전 세계 누구나 접속할 수 있는 내 스마트 명함 링크가 완성됩니다!

### 옵션 B: Vercel 또는 Netlify Drop
1. [vercel.com](https://vercel.com) 또는 [netlify.com](https://netlify.com)에 무료 가입합니다.
2. 이 폴더를 드래그 앤 드롭하기만 하면 10초 만에 정식 HTTPS 웹 주소가 발급됩니다.

## 📱 실물 NFC 카드/스티커 활용 팁

인터넷 쇼핑몰(네이버, 쿠팡 등)에서 **NTAG213 / NTAG215 스티커(개당 300~500원)**를 구매하신 후:
1. 본인의 배포된 명함 URL을 복사합니다.
2. 무료 앱(`NFC Tools` 등)을 스마트폰에 설치한 뒤, **[쓰기] -> [URL 추가]**를 선택하고 링크를 붙여넣습니다.
3. NFC 스티커에 스마트폰을 탭하면 기록 완료!
4. 이제 스마트폰 뒷면이나 지갑에 스티커를 붙이고, 상대방 스마트폰에 갖다 대기만 하면 명함이 즉시 화면에 뜹니다.
